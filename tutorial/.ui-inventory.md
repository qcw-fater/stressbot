# stressbot 管理面 UI 全量清单（点击顺序树）

> 用途：给截图/点测代理逐项点击的核对表。唯一事实来源是 `cmd/web/src`（2026-10 版本）。
> 路径均相对 `cmd/web/src/`；行号为该标签/控件在源码中的近似位置（±5 行）。
> 记法：`「文案」` = 界面原文；`⟂` = 禁用/隐藏条件；`API` = 调用的后端端点（前缀 `/sbot`，基线前缀 `/sbot/baseline`）；`本地` = 只写浏览器本地存储（IndexedDB / LocalStorage）。
> 运行模式（runtimeStore.mode）：`edit` 编辑 / `running` 本端启动的任务运行中 / `viewActive` 监测他人或已存在任务 / `finalReport` 任务终态。除 `edit` 外画布只读（readOnly）。

## 2. 流程编辑器 `components/FlowEditor/`

### 2.1 启动行为（`index.tsx`）
- 有本地草稿 → 恢复并右上角通知「已恢复编辑稿」「上次保存于 …」；否则 API `GET /baseline/flow/flow.json` 载入基线流程。
- 加载 proto：本地存储 → API `GET /baseline/proto/index.json` + 各文件 → 编译期内联兜底。
- 全局热键（`index.tsx`）：Ctrl/Cmd+Z 撤销；Ctrl/Cmd+Shift+Z 或 Ctrl+Y 重做（焦点在输入框/脚本编辑器内时不拦截；只读时无效）。

### 2.2 左侧面板 `panels/NodePalette.tsx`（宽 240；⟂ readOnly 时整块隐藏）
- 区块标题「节点类型」，10 个格子（拖入画布创建；tooltip「{说明} · 拖入画布创建 {名} 节点」）：

- 模板库（需服务器 `capabilities.templateLibrary=true`，否则整块显示 Empty「正在确认共享模板库状态」/「共享模板库功能未启用，请检查服务器配置」）

    - 右键菜单：「编辑模板」/「复制到剪贴板」（提示「已复制（在画布空白处右键 → 粘贴）」）/「删除模板」（无确认；API `DELETE /action-templates/{id}` 或 `/listen-templates/{id}`）。
  - 面板内无重命名/导入/导出功能。

- 分组：流程（已保存流程*、当前编辑稿）/ 资源（Proto 文件、Lua 脚本、协议配置、错误码）/ 模板库（动作模板*、监听模板*）/ 工具（笔记文件）；每行显示「N 项 · 大小」或「读取中 / 读取失败：…」；*需服务器启用，未启用显示「服务器未启用流程库 / 服务器未启用共享模板库」（检查中「正在检查…」）并禁用。
- 说明「备份文件可能包含业务协议、脚本和笔记内容，请妥善保管；不包含服务器连接、数据库凭据、运行历史和界面偏好。」
- footer「取消」/「下载备份」（⟂ 未选分区；失败 Alert「备份未生成」）。读取：本地 + API `GET /flows/snapshot`、`GET /action-templates/snapshot`、`GET /listen-templates/snapshot`。

### 9.2 「恢复配置」`ConfigRestoreModal.tsx`（宽 760）
- 「选择备份文件」+ 文件名/「尚未选择文件」；读取失败 Alert「无法读取备份」。
- 「格式版本 N」「导出时间 …」；「选择恢复内容」+「全选」「清空」；每分区勾选 +「N 项」。
- 「恢复方式」Segmented「合并导入 / 完整恢复」；合并时「重复内容」：全部覆盖 / 逐个处理 / 全部忽略；完整恢复时警告「完整恢复会删除选中内容中备份不存在的配置」。
- 非编辑模式警告「请先返回编辑模式」（禁用恢复）；预览失败「无法生成恢复预览」。
- 预览「预计变化」：每分区「新增 / 覆盖 / 删除 / 忽略 / 保留两份」。
- 「处理重复内容」（逐个处理时）：每项「目标：…」+ 来源更新时间等，单选「覆盖 / 保留两份 / 忽略」+「应用到剩余同类冲突」。
- footer「取消」/「开始恢复」→ 确认「确认合并导入」（「将按照预览结果合并选中的配置内容。」）或「确认完整恢复」（「选中内容将与备份保持一致，备份中不存在的配置会被删除。」）ok「确认恢复」。
- 结果页：「恢复完成 / 配置恢复未完成 / 恢复失败，已撤销本次修改 / 恢复失败，未修改配置」+ 统计 +「仍有内容等待撤销」；footer「关闭」。
- 写入：本地 + API `PUT /flows/snapshot`、`PUT /action-templates/snapshot`、`PUT /listen-templates/snapshot`。
