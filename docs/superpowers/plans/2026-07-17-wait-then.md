# Wait Then Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 支持 wait 节点通过 `then` 保存并执行唯一后继节点。

**Architecture:** `then` 作为 wait 专用的可选节点引用，前端由 React Flow 的 `out` 锚点写入并派生 `waitThen` 边，后端在协作式等待成功后递归执行目标节点。现有 `sequence.next` 和无 `then` 的旧配置保持不变。

**Tech Stack:** Go、React 18、TypeScript、Zustand、@xyflow/react、Vitest

- [ ] **Step 3: 实现连接解析器和 store 引用维护**

```ts
export function resolveWaitConnection(
  source: FlowNode,
  sourceId: string,
  sourceHandle: string,
  targetNodeId: string | null,
): WaitConnectionResult {
  if (source.type !== 'wait' || sourceHandle !== 'out') return { matched: false };
  if (!targetNodeId) return { matched: true, error: 'wait 节点只能连接普通节点' };
  if (targetNodeId === sourceId) return { matched: true, error: 'wait 节点不能指向自身' };
  return { matched: true, patch: { then: targetNodeId } };
}
```

`FlowCanvas.onConnect` 使用解析结果更新节点或显示中文 warning；`deleteRfEdge` 对 `wait/out` 清空 `then`。`flowStore` 将 `then` 加入拓扑字段，并在删除、重命名节点时维护引用。
