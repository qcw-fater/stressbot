# 启动表单常用字段文案设计

## 目标

统一启动表单四个常用字段的标签和辅助文案密度，消除无说明、短默认值和场景教学长文案混排造成的视觉失衡。

## 文案规则

四项统一采用短标签和一行短说明：

| 标签 | 辅助说明 |
| --- | --- |
| 机器人数 | 集群总容量 `{totalCapacity}` |
| 并发 | 每秒新建机器人数 |
| 账号前缀 | 默认 `bot_` |
| 起始编号 | 默认 `0` |

移除账号格式公式、历史账号避撞示例、调试建议和峰值并发等常驻长说明。调试模式已由弹窗顶部模式区说明，阶段数量与峰值信息已由阶段性测试区域表达，不在常用字段下重复。

## 组件调整

`TaskStartCommonFields` 保留原输入值、范围、更新回调和响应式两列布局。删除只为旧辅助文案服务的 `debugMode`、`peakBots` 和 `hasResetStage` props，父弹窗不再传递这些参数。

## 验证

- 更新组件测试，断言四个短标签及对应一行说明。
- 断言账号公式和避撞示例不再出现。
- 运行聚焦 Vitest、TypeScript 编译和前端完整测试。
