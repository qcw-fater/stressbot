# 启动表单常用参数布局设计

## 目标

将账号前缀和账号编号起点从“高级设置”移到启动任务主表单，与人数、并发组成两行两列的常用参数区：

```text
人数    并发
前缀    编号
```

## 界面与交互

- 桌面宽度下使用等宽两列；窄窗口下自动堆叠为单列，避免标签、说明或输入值相互挤压。
- 第一行保留现有“集群总机器人数”和“并发（每秒新建机器人数）”行为。
- 阶段性测试开启时，人数位置继续显示各阶段自动累加的只读汇总。
- 第二行显示“账号前缀”和“账号编号起点”，保留现有默认值、说明、取值范围和状态更新逻辑。
- “高级设置”中移除这两个字段，并从折叠面板摘要中移除账号相关描述。

## 数据与错误处理

本次只调整 JSX 布局。`robotConfig.accountPrefix`、`robotConfig.startNumber`、`totalBots` 和 `robotConfig.concurrency` 的读写、持久化与任务提交协议均保持不变，不引入新的错误分支。

## 验证

- 新增组件测试，确认四个常用参数按预期归入两行两列区域，账号字段不再位于高级设置内容中。
- 运行相关 Vitest、TypeScript 编译检查和前端完整测试。
